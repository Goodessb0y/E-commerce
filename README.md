# Интернет-магазин

## Описание проекта

Проект интернет-магазина, реализованный с использованием объектно-ориентированного подхода (ООП).

На текущем этапе реализованы:
- классы `Product` и `Category` для представления товаров и категорий;
- создание экземпляров классов с необходимыми атрибутами;
- загрузка данных из JSON-файлов;
- преобразование данных из JSON в объекты Python.

## Реализованные классы

### Product

Класс представляет товар интернет-магазина.

Основные атрибуты:
- название товара;
- описание;
- цена;
- количество.

### Category

Класс представляет категорию товаров.

Основные атрибуты:
- название категории;
- описание категории;
- список товаров.

## Работа с JSON

Реализована функция загрузки данных из JSON-файла:

- чтение данных из файла;
- создание объектов `Product`;
- создание объектов `Category`;
- связывание товаров с соответствующими категориями.
